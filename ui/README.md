# Get started

npm install

## Configure WebStorm for Vite

### 1. Run configuration   
Click the dropdown next to the Run button → Edit Configurations… → + → npm.
Name it “Vite dev”.
Set Command to run.
Set Scripts to dev (the script created by Vite).
Apply & OK.
### 2. Enable automatic reload   
WebStorm detects Vite’s hot‑module replacement automatically, so you can just press Run on the new configuration and the browser will open at http://localhost:5173.
