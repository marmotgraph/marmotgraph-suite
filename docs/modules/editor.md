# Editor

The editor is where instances are curated: you browse the instances of the spaces you can read, open them to see and
change their values, and release them once they are ready.

## Finding instances

The instance list can be filtered - for example to show only your favorites or only the instances you contributed to.

## Editing an instance

An instance is shown with the fields of its type. Besides the values, you can see

- the links to other instances and the instances linking to it,
- the comments on the instance,
- the validation result against the schemas of its type,
- and its raw JSON.

Changes are kept as unsaved changes until you save them - including newly created linked instances.

## Releasing

Saved changes are drafts until they are released. The release view shows which linked instances are released along
with the instance.
