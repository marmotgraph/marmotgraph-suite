# Modeler

The modeler defines the structure of the graph: the types, their properties and how they relate to each other. It is
only available to administrators.

## Types

For each type you can define its identifier, the spaces it is used in and its properties. The type graph shows how the
types are linked.

## Properties

A property defines how a value is entered in the editor - the widget preview shows how the field will look.

## Validation schemas

Validation schemas attached to a type are used to score the instances of that type. They never block anybody from
saving - they make the quality of the data visible.
