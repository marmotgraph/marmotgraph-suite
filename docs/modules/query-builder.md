# Query Builder

The query builder lets you describe the shape of the result you want - starting from a type and following its
properties and links - without writing the query by hand.

## Building a query

Pick a root type, add the properties you are interested in and configure them. The JSON of the query can be edited
directly as well.

## Running and saving

Queries can be executed right away to look at the result. Saved queries are either private or stored in a space, where
the people with access to that space can use them too.
